# Эхо — сборка iOS

`index.html` скопирован без изменений. Остальные файлы подготовлены для сборки через GitHub Actions.

## Содержимое проекта

- `App.swift` — нативная оболочка iOS на Swift + WKWebView.
- `index.html` — твой исходный интерфейс; этот файл не редактировался.
- `project.yml` — спецификация проекта для XcodeGen.
- `make_icon.py` — создаёт `Assets.xcassets` и иконку приложения.
- `.github/workflows/build.yml` — автоматическая сборка IPA в GitHub Actions.

## Как загрузить проект на GitHub

1. Создай новый пустой репозиторий на GitHub.
2. Распакуй архив `Echo-iOS-project.zip` на компьютере.
3. Загрузи **содержимое папки `Echo-iOS`**, а не саму папку, в корень репозитория. Должны быть видны `App.swift`, `index.html`, `project.yml`, `make_icon.py` и папка `.github`.
4. Сделай Commit changes в ветку `main`.
5. Открой вкладку **Actions** в репозитории.
6. Выбери workflow **Build unsigned IPA** и нажми **Run workflow**. При загрузке изменений в `main` он также запускается автоматически.
7. Дождись зелёной галочки, открой завершённый запуск workflow и найди раздел **Artifacts** внизу страницы.
8. Скачай `Echo-unsigned-ipa` и распакуй ZIP-архив артефакта. Внутри будет `Echo-unsigned.ipa`.

## Важно про установку на iPhone

Эта автоматизация собирает **неподписанный IPA** (`CODE_SIGNING_ALLOWED=NO`). Это проверка сборки и упаковки, а не готовый к установке файл. iPhone не установит его напрямую.

Для установки нужна подпись:
- для личной установки можно подписать IPA через AltStore/Sideloadly с Apple ID (у бесплатной подписи есть ограничения по сроку и числу приложений);
- для распространения через TestFlight или App Store нужна соответствующая подпись и учётная запись Apple Developer.

Не публикуй сертификаты, приватные ключи или пароли в открытом репозитории.

## Примечания

- Bundle ID: `com.echoplayer.app`.
- Минимальная версия iOS: 15.0.
- Фоновый аудиорежим включён в настройках приложения; фактическое поведение фонового воспроизведения зависит также от ограничений iOS и WebKit.
- Треки и данные HTML-приложения хранятся локально на устройстве. Удаление приложения может удалить эти данные.
