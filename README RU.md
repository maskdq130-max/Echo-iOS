# Эхо

Личный музыкальный плеер для iPhone. Весь звук, обложки и аккаунты хранятся только на твоём телефоне: никаких серверов, рекламы и подписок.

Приложение — это нативная оболочка на Swift (`WKWebView`) вокруг одного файла `index.html`. Страница лежит внутри приложения и открывается локально, поэтому интернет для запуска не нужен.

## Возможности

- Добавляй треки из файлов или галереи: mp3, m4a, wav, mp4, mov (из видео берётся только звук).
- Название, исполнитель и обложка подтягиваются из ID3-тегов. Всё можно поменять вручную.
- Играет как настоящий музыкальный плеер: фон, экран блокировки, пульт в Пункте управления, наушники и Bluetooth.
- Музыка не глохнет при выключенном экране.
- Избранное, поиск, сортировка, перемешивание, повтор списка или одного трека, таймер сна.
- Скорость воспроизведения от 0.5× до 1.5×.
- Визуализатор в трёх стилях и живая гифка на главной.
- Свой аватар: выбери фото из галереи, оно обрежется по кругу.
- Тёмная и светлая темы, цвет акцента, экономия батареи.
- Несколько аккаунтов на одном телефоне.

### Как включить Премиум

- Кнопка «Получить Премиум» в Профиле или в Настройках.
- Или промокод: Профиль → Эхо Премиум → «Промокод».

### Настройка премиума в коде

Всё в начале скрипта `index.html`:

```js
var FREE_LIMIT=30, PRO_PRICE='199 ₽', DEMO_BUY=true, PROMOS=['...'];
```

- `FREE_LIMIT` — сколько треков доступно без премиума.
- `PRO_PRICE` — цена на кнопке.
- `DEMO_BUY` — пока `true`, кнопка «Получить Премиум» включает премиум без оплаты (тестовый режим). Поставь `false`, чтобы премиум включался только промокодом или реальной покупкой.
- `PROMOS` — хэши промокодов. Хэш считает функция `h53(КОД_ЗАГЛАВНЫМИ, 7)`.

> **Важно.** Это встроенная система премиума без настоящей оплаты. Приложение, собранное без подписи и установленное через Sideloadly или AltStore, не может принимать платежи Apple. Для реальных покупок нужны платный аккаунт Apple Developer, товар в App Store Connect и StoreKit в `App.swift`. Для этого в `index.html` уже есть мост: он отправляет `{action:'buy'}` и `{action:'restore'}` в обработчик `echoIAP` и ждёт ответ через `window.echoProResult(true|false)`. Промокоды проверяются на телефоне и подходят для подарков друзьям, но не защищают от взлома.

## Как собрать IPA

Сборка идёт на GitHub Actions, свой Mac не нужен.

1. Залей файлы в репозиторий: `App.swift`, `index.html`, `project.yml`, `icon.png`, `make_icon.py`, `Contents.json`, `.github/workflows/main.yml`.
2. Открой вкладку **Actions**, выбери **Build unsigned IPA** и нажми **Run workflow** (или просто сделай push в `main`).
3. Через 1–2 минуты в запуске появится артефакт **Echo-IPA**. Скачай его и распакуй, внутри лежит `Echo.ipa`.

Что делает сборка: рисует иконку (`make_icon.py`), создаёт Xcode-проект из `project.yml` через XcodeGen и собирает IPA без подписи.

## Как установить на iPhone

IPA собирается без подписи, поэтому его нужно подписать своим Apple ID. Подойдут Sideloadly, AltStore или TrollStore (если он поддерживает твою версию iOS).

С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней.

## Фоновое воспроизведение

- Музыка играет через обычный `<audio>`, поэтому iOS показывает её как песню и не останавливает при блокировке экрана.
- Включена фоновая работа аудио (`UIBackgroundModes: audio`) и аудиосессия `playback`.
- Эхо, эквалайзер и 8D подключаются через Web Audio. Пока они выключены, звук идёт напрямую. Если с эффектами звук глохнет при блокировке экрана, сбрось их и перезапусти приложение.
- Визуализатор без эффектов работает в декоративном режиме (не по реальному спектру). С эффектами он показывает настоящий спектр.

## Структура проекта

| Файл | Что внутри |
|---|---|
| `index.html` | Весь интерфейс и логика плеера |
| `App.swift` | Оболочка `WKWebView`, схема `echo://`, аудиосессия |

## Обновление

Правки в `index.html` попадают в приложение только после новой сборки и переустановки IPA. Если ставить поверх старой версии, треки и аккаунты сохраняются.

## Конфиденциальность

Приложение ничего не отправляет в интернет. Аккаунты, треки, обложки, аватары и статус премиума лежат в памяти приложения на этом телефоне.
